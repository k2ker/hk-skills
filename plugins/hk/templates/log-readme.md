# docs/log/ — 조각 로그

일단락된 작업의 기록이 쌓이는 **유일한 장소**. 파일명 정렬이 곧 연대기다. 규칙 정본은 hk `record` 스킬 — 여기는 로컬 요약.

1. **일단락되면 조각 하나** — `YYYY-MM-DD-주제슬러그.md`. **순번 없음**(병렬 충돌 차단), 같은 날 같은 슬러그만 브랜치명 접미.
2. **frontmatter**: `date` · `type: note|lesson|incident|decision` · `refs`(커밋·관련 조각).
3. **박제 — 번복은 새 조각으로.** 과거 조각은 고치지 않는다. 뒤집히면 새 조각 + `refs`에 옛 조각. 후속절 append는 오너만.
4. **"지금 뭐가 맞나"는 `MEMORY.md`·`CLAUDE.md`에서 읽는다** — 조각은 당시 기록이다.
5. **단일 기록자** — 병렬 워커는 쓰지 않는다. 보고만 하고 리드가 랜딩 때 기록.
6. **정본 중복 금지** — 코드·git·CLAUDE.md가 이미 갖는 내용은 쓰지 않는다.
7. **병목 금지** — 일단락 시 1회. trivial 면제. 쓸 사실·결정·교훈이 없으면 쓰지 않는다.

조회: 연대기 = `ls`, 유형별 = frontmatter grep. 이관 전 옛 기록은 git 이력에서 (`git show <ref>:<path>`).
