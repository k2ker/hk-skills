# docs/log/ — 조각 로그 (기록 컨벤션 v2)

일단락된 작업의 기록이 쌓이는 **유일한 장소**. 파일명 정렬이 곧 연대기다. 규칙 정본은 hk 플러그인 `record` 스킬 — 여기는 요약.

1. **일단락되면 조각 하나** — `YYYY-MM-DD-주제슬러그.md`. **순번 없음**(병렬 충돌 원천 차단), 같은 날 같은 슬러그만 브랜치명 접미.
2. **frontmatter**: `date` · `type: note|lesson|incident` · `refs`(D번호·커밋·관련 조각). 결정은 조각이 아니라 `docs/DECISIONS.md`(항목 3줄 상한).
3. **단일 기록자** — 병렬 워커는 조각을 쓰지 않는다. 보고만 하고 **리드가 랜딩 때 기록**. 워커 면제 마커는 git 메타데이터에(`record` 스킬의 워커 마커 규약).
4. **정본 중복 금지** — 코드·git·DECISIONS·전용 장부가 이미 기록하는 내용은 쓰지 않는다.
5. **MEMORY.md는 책갈피** — 열린 항목만 3줄 이내. **닫히면 MEMORY에서 지우고 조각으로 내린다.**
6. **박제 — 번복은 새 조각으로** — 과거 조각은 고치지 않는다. 뒤집히면 새 조각 + `refs`에 옛 조각. "지금 뭐가 맞나"는 MEMORY·CLAUDE.md·DECISIONS에서만 읽는다.
7. **후속절은 오너만** — 남의 조각엔 새 조각 + refs.
8. **병목 금지** — 기록은 일단락 시 1회. trivial 작업은 면제. 쓸 사실·결정·교훈이 없으면 쓰지 않는다.

조회: 연대기 = `ls`, 유형별 = frontmatter grep. 이관 전 옛 기록의 참조는 git 이력에서 (`git show <ref>:<path>`).
