# 기록 컨벤션 — 조각 로그 + MEMORY

목적: 어느 PC·어느 세션이 와도 프로젝트의 히스토리("무슨 일이 있었나")와 현재 상태("지금 뭘 알아야 하나")를 싸게 복원한다. 병렬 세션·워크트리에서 충돌 없이. **기록이 작업의 병목이 되면 안 된다.**

## 구조

| 파일 | 역할 | 수명 |
|---|---|---|
| `docs/log/YYYY-MM-DD-주제.md` | **조각** — 일단락된 작업의 박제 기록(연대기) | 쌓임, 안 고침 |
| `MEMORY.md` | **지금 참인 것** — 미결 · 사용자/작업 방식 · 제약·함정 · 참조 · 인덱스 | 덮어씀, 닫히면 지움 |
| `docs/DECISIONS.md` | **선택** — D번호 참조 체계를 쓰는 프로젝트만. 기본은 조각 `type: decision` | 쌓임 |
| `CLAUDE.md` | 항구 규칙 — 여러 세션을 살아남는 계약의 승격지 | 규칙 정본 |

새 세션 동선: `MEMORY.md`를 읽고 시작 → 맥락이 더 필요하면 `ls docs/log/`로 거슬러 읽는다.

## MEMORY.md에 담는 것 (내장 메모리 대용 — git이라 PC 무관)

- **미결/진행 중** — 하다 만 것, 대기 중인 결정, 누가 막고 있는지
- **사용자·작업 방식** — 선호·교정(반복 지적을 막는 항목)
- **제약·함정** — 코드만 봐선 모르는 전제·지뢰
- **참조** — 외부 자료 포인터
- **담지 않는 것**: 코드·git 이력·CLAUDE.md·전용 장부가 이미 갖는 내용, 지나간 일의 서사(그건 조각)

## 조각 규칙

- 파일명 `YYYY-MM-DD-주제슬러그.md` — **순번 금지**(병렬 세션의 번호 경쟁·머지 충돌 차단). 같은 날 같은 슬러그가 겹치면 브랜치명 접미.
- frontmatter: `date`, `type: note|lesson|incident|decision`, `refs`(커밋·관련 조각·뒤집는 조각).
- **박제** — 과거 조각 본문은 고치거나 지우지 않는다. 뒤집히면 **새 조각 + refs에 옛 조각**(전방 링크 의무).
- **후속절 append는 박제의 유일한 예외** — 그 조각의 오너만. 남의 조각엔 새 조각 + refs.
- **"지금 뭐가 맞나"는 조각에서 읽지 않는다** — 현재 상태 정본은 MEMORY·CLAUDE.md뿐.

## 쓰기 전 필터

- **정본 중복 금지** — 코드·git·CLAUDE.md·전용 장부가 이미 기록하는 건 쓰지 않는다. 코드·git으로 알 수 없는 것(경위·실측·교훈·철회된 제안)만.
- **한 곳에만** — 같은 내용은 한 집에, 나머지는 링크.
- **trivial 면제** — 오타·사소한 설정·대화뿐인 턴은 조각을 만들지 않는다. **게이트 통과용 서사 금지** — 쓸 사실·결정·교훈이 없으면 쓰지 않는다.
- **승격** — MEMORY의 제약·함정이 항구화되면 CLAUDE.md로 승격 제안(승인 후 이동).

## 병렬·위임 — 단일 기록자

- **병렬 워커는 기록하지 않는다.** 보고(worker_done 등)로 리드에게 넘기고, **리드가 랜딩 때 1회** 기록한다. 워커 N명이 돌아도 기록 파일을 만지는 손은 하나 — 충돌이 구조적으로 없다.
- **워커 마커**(오케스트레이터 중립 규약): 워커를 띄우는 주체가 `touch "$(git -C <워커경로> rev-parse --absolute-git-dir)/hk-worker"`. **반드시 `--absolute-git-dir`**(상대 경로는 실행 셸 cwd 기준으로 풀려 엉뚱한 repo를 오염시킨 실측 사고가 있다). git 메타데이터라 커밋에 섞일 수 없고 워크트리 제거와 함께 사라진다. 게이트가 1ms에 감지해 면제.

## 조회

연대기 = `ls docs/log/` · 유형별 = frontmatter grep(`grep -l "type: lesson" docs/log/*.md`) · 이관 전 옛 기록 = git 이력(`git show <ref>:<path>`).

## 적용

`/hk:record:setup` — 하나로 통합됐다. `docs/log/` 있으면 **보충 모드**(비파괴·조각 재처리 금지·잔여는 보고만), 없으면 **적용 모드**(발굴→뼈대→분류→원본 정리→검증). 재실행해도 안전하다.
