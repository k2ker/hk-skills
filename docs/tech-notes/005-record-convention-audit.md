# 005 — 기록 컨벤션 감사: 겹침의 실체 (2026-08-19)

사용자가 DECISIONS·MEMORY·tech-note의 겹침을 지적해 감사한 결과. **진단 사실만 기록** — 규율 제정·정리 여부는 별도 결정 사안.

## 확인된 겹침 5건

1. **DECISIONS 항목이 조사 서사를 포함** — 예: "MCP 2종 동봉" 항목이 스캔 결과·제외 근거·마이그레이션 절차까지 6줄, "도입 보류" 항목이 흡수 매핑 5줄. 결정 자체는 각 1줄이면 충분한 내용.
2. **tech-note에 결정성 내용 존재** — 004의 "도입 난이도 분류" 표(사실상 권고), 003의 "함의" 섹션.
3. **미결 추적이 이원화** — DECISIONS의 Hermes 항목 내부 "후속 미결"과 MEMORY.md의 미결 섹션이 같은 항목을 중복 추적.
4. **MEMORY 인덱스 줄의 비대화** — 004 인덱스 줄에 발견 요약 3건이 들어가 인덱스가 내용 중복으로 변질.
5. **세션 메모리(유저 레벨)와 repo 기록의 중복** — 유저 레벨 orca 메모리 파일과 tech-note 001이 상당 부분 동일 내용.

## 원인 관찰

Stop 기록 훅이 턴마다 기록을 요구 → 훅 통과를 위해 당시 맥락을 통째로 DECISIONS에 기입한 턴들이 존재. 기록이 "훅 통과용"으로 작성되면 장부가 서사로 오염된다는 것이 실측됨. 구조(3파일 분리) 자체의 결함이 아니라 분업 규율 부재가 원인이라는 것이 대안 검토(상호 흡수 시나리오) 결과.
